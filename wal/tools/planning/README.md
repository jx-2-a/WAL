# Planning Tools (规划工具)

14 个规划模式工具，用于剧情分析和创作规划。

## 分析工具

| 工具 | 参数 | 说明 |
|------|------|------|
| `suggest_plot_direction` | [focus] | 建议剧情发展方向 |
| `brainstorm_character_arc` | char_id | 角色弧光头脑风暴 |
| `analyze_plot_holes` | — | 分析剧情漏洞 |
| `propose_plot_twist` | [context] | 提议剧情转折 |
| `evaluate_pacing` | [chapter_range] | 评估节奏 |
| `suggest_conflict_escalation` | [plot_id] | 建议冲突升级 |
| `brainstorm_world_building` | [aspect] | 世界观构建头脑风暴 |
| `analyze_theme_consistency` | — | 分析主题一致性 |

## 笔记管理

| 工具 | 参数 | 说明 |
|------|------|------|
| `add_planning_note` | title, content, [tags] | 添加规划笔记 |
| `list_planning_notes` | [tags] | 列出笔记 |
| `get_planning_note` | note_id | 获取笔记 |

## 其他

| 工具 | 参数 | 说明 |
|------|------|------|
| `switch_mode` | mode | 切换到 writing/planning/autonomous |
| 记忆工具 | — | 同 shared/memory |
